# 🎮 Rock Paper Scissors Shoot

A **pixel-art Rock Paper Scissors game** developed entirely in **Python** as a personal project.

I created this project from scratch, combining programming with **pixel art, animation, UI/UX, sound design, and game design**.

## ✨ Features

- 🎮 Rock, Paper, Scissors gameplay
- 👥 Player vs Player gameplay
- 🤖 Player vs Computer gameplay
- 🏆 Round-based scoring system
- 👤 Character selection
- 🎬 Animated hand sequences and countdown
- ✊ Rock / 📄 Paper / ✂️ Scissors animations
- 🖱️ Interactive buttons and hover effects
- ⏸️ Pause system
- 🔊 Sound effects
- 🎵 Background music with volume controls
- 🏅 Winner and score screens
- 🎨 Custom pixel-art interface and characters

## 🎨 Art & Animation

All of the pixel-art visuals used in the game were created by me using **Resprite**.

This includes the game's:
- Characters
- Hands
- Buttons
- Menus
- UI elements
- Game screens
- Visual animations

The hand animations and game sequences are then **animated and controlled through Python**.

## 🛠️ Technologies

- **Python**
- **Tkinter** — graphical user interface
- **Pillow (PIL)** — image processing and pixel-art rendering
- **Pygame** — sound effects and background music

## 🔊 Sounds

The sound effects used in the game were sourced from **Pixabay**.

## 🚀 Running the Game

### Requirements

Make sure Python is installed, then install the required libraries:

```bash
pip install pillow pygame
```

### Launch

Keep the Python file and all required image, GIF, MP3 and other asset files in the same project directory.

Then run:

```bash
python "rock paper scissor.py"
```
